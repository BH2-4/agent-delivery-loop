# ADR-0007 草案：当前单机阶段采用细粒度 PAT

日期：2026-10-05。状态：**草案（已被 [docs/adr/0007-fine-grained-pat-stage.md](adr/0007-fine-grained-pat-stage.md) 正式化；本文件保留为历史草案）**。

本文件位于 `docs/adr/` 之外，未修改现有 ADR 状态。用户已确认 PAT 方向并授权实现；凭据和下一轮实验仍未获准启动。拟在确认后新增 `docs/adr/0007-fine-grained-pat-stage.md`，并将 ADR-0002 标为被本决策替代（限当前阶段身份选择），保留其历史全文、风险和 App 接口。

## 背景

单机实验已验证一部分 GitHub 机械交付，但长期身份尚未接入。Mac 上维护 App 私钥、签发与 OS 隔离的成本较高；用户选择更简单的细粒度 PAT，要求保留 App 与托管 Actions 备选。

## 决定

当前单机阶段用仅选择目标仓库、具有有限期限的细粒度 PAT。外层编排器显式读取仓库外私有文件，绑定预期账号与仓库；不读取日常 `gh` 登录，不把凭据传给 Worker／审查子程序，失败不回退其他身份。

App 不再是当前阶段推进的前置条件，但它的接口与门禁不被挪作 PAT 后门。具体 GitHub 写操作、合并和长线 Goal 由独立的范围清单、时间窗与授权决定，不能由本 ADR 自动授予。

## 备选

- 日常个人 `gh`：人工工具保留，拒绝把已结束的限次授权变成长期授权。
- 内置 `GITHUB_TOKEN`：保留托管工作流路线，但存在事件触发与本地成果交接约束。
- App + 托管 Actions：保留独立身份与移出 Mac 私钥的方向，暂不增加云端发布部署。
- App + Mac 独立发布用户／进程：保留更强本地边界，暂缓系统级隔离工程。

## 后果

接入更简单、日常配置不被覆盖，发布／回读身份明确。但 PAT 仍是个人身份，需要手动续期／撤销；`Contents:write` 也可能允许合并，不能宣称主线被令牌权限硬性保护。同用户下文件模式与环境清理不证明 OS 隔离。

CI 采用明确支持细粒度 PAT 的 Actions REST 运行／jobs 读取，仅申请 `Actions:read`，避开 Checks API 支持的不确定性。固定当前仓库的 `ci.yml`／`validate` 契约，不声称查询全部外部检查或主分支保护要求。

真实 PAT 权限、Actions REST 账号兼容性、写入和当前主分支规则仍须实测；源码、安装和真实链路分别记录状态。认证／权限不确定就停止，不扩大权限、切换 classic 或伪造验证标记。
