# ADL 一句话接班（Codex 仓库级入口）

用户在目标仓库的新会话中说「接班这个项目」，或显式调用 `$adl`，即触发本 Skill。

## 怎么做

1. 打开仓库根目录 [`docs/bootstrap.md`](../../../docs/bootstrap.md) 的「一句话接班」一节，严格按该节执行。
2. 详细流程只维护在该节；本 Skill 不复述项目历史、当前状态或证据，不在会话中重写它们。

## 边界

- 只读梳理：不启动 Worker，不执行 `launch` / `deliver` / `resume`，不推送、合并、安装、部署或清理状态。
- 不读取或展示认证文件、凭据、认证值、本机私有路径或完整会话；不新增状态文件、数据库或状态副本。
- 不继承旧执行授权；接班结束后的执行服从用户明确的新指令与现有授权流程。
- 最后简短汇报当前完成情况、实际阻塞或未核对项、一个推荐下一步。
